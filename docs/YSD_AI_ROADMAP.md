## المرحلة 1 — MVP
- 🟢 واجهة المحادثة الكاملة: بث SSE، إيقاف التوليد، إعادة توليد، تعديل رسالة المستخدم، Markdown + كتل كود مع نسخ، اختيار النموذج
- 🟢 المصادقة الكاملة: دخول، تسجيل مع تأكيد بريد، نسيان/إعادة تعيين كلمة المرور، خروج، حماية الصفحات
- 🟢 حفظ واسترجاع المحادثات من قاعدة البيانات (إنشاء/حذف ناعم/إعادة تسمية/عنوان تلقائي/بحث)
- 🟢 الهيكل: شريط جانبي قابل للطي، متجاوب للجوال، وضع داكن/فاتح، عربي RTL/إنجليزي LTR
- 🟢 صفحة الحساب: الملف الشخصي (الاسم) + الباقة + عداد الاستهلاك الشهري الحقيقي (رسائل + Tokens)
- 🟢 صفحة الإعدادات: المظهر، اللغة، النموذج الافتراضي (تُحفظ في user_preferences)
- 🟢 migration 0002: سياسات تعديل الرسائل وتسجيل الاستهلاك
- 🟢 قاعدة البيانات مطبّقة على Supabase (16 جدولًا + 23 سياسة + trigger + seed) — تم التحقق سلوكيًا
- 🟢 اختبارات Runtime حقيقية (scripts/runtime-check.mjs): 38/38 — تسجيل، trigger الملف الشخصي، جلسات، CRUD محادثات ورسائل، عزل RLS بين مستخدمين، IDOR عبر API، رسالة خطأ عربية عند نفاد رصيد الموفر دون تسريب أسرار
- 🟢 بث Streaming حقيقي عبر OpenRouter المجاني — مُختبر من المتصفح (إرسال + إعادة توليد + حفظ)
- 🟢 جودة اللغة: Allowlist نماذج مجانية مُتحقق منها بالعربية + Language Guard (نافذة فحص + إعادة محاولة بنموذج احتياطي) + اختبارات آلية 12 + اختبار حي 4/4
- 🟢 التقاط النموذج الفعلي من OpenRouter وتسجيله في messages/usage_events وعرضه في وضع التطوير
- 🟡 بث Anthropic — بانتظار إضافة رصيد API (معالجة الخطأ مُختبرة ومؤكدة)
- ⚪ صورة الملف الشخصي وحذف الحساب

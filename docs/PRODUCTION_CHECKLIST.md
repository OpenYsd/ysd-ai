# قائمة التحقق قبل الإطلاق — YSD AI

## البيئة والأسرار
- [ ] كل المتغيرات المطلوبة مضبوطة (`GET /api/health` → `env.ok = true`).
- [ ] `YSD_STRICT_ENV=1` في الإنتاج (يوقف الإقلاع عند نقص متغير).
- [ ] لا مفتاح سري في أي `NEXT_PUBLIC_*`.
- [ ] `SUPABASE_SERVICE_ROLE_KEY` غير موجود (العامل المستقل غير مُفعّل) أو مُؤمّن على الخادم فقط.
- [ ] `.env.local`/`.env` خارج Git (مؤكّد في `.gitignore`).

## قاعدة البيانات
- [ ] الترحيلات `0001`→`0008` مطبّقة.
- [ ] RLS مُفعّل على كل الجداول، ومُختبر بين مستخدمين (rag-check + stress 20/20).
- [ ] صلاحيات دوال `0008`: `authenticated` للمقيّدة بالمالك فقط، `cleanup` لـ service_role فقط.
- [ ] pgvector مُفعّل ودالة `match_file_chunks` تعمل (`/api/health` → pgvector ok).
- [ ] `cron.schedule` للتنظيف الدوري مُجدول.

## التخزين
- [ ] Bucket `files` خاص (غير عام) — `0006` مطبّق.
- [ ] سياسات Storage الأربع تفرض بدء المسار بمعرّف المستخدم.
- [ ] حد الحجم 50MB مطابق لخطة المزود.

## الأداء والذاكرة
- [ ] الخادم دائم (لا Serverless) بذاكرة ≥ 2GB (يُفضّل 4GB).
- [ ] `YSD_LOW_MEMORY=1` على خوادم ≤ 2GB.
- [ ] كاش النموذج (`.cache/transformers`) على قرص دائم أو يُحمّل عند الإقلاع.
- [ ] تزامن Embeddings = 1 (مؤكّد)، نسخة نموذج واحدة (guard مُفعّل).

## المتانة
- [ ] فشل خدمة واحدة لا يُسقط المنصة (deployment-check ناجح).
- [ ] أخطاء الموفر تصل كرسائل عربية دون تسريب أسرار.
- [ ] فشل استرجاع RAG لا يمنع المحادثة.
- [ ] المهلات مضبوطة (موفر 60ث، embedding 120/180ث، صحة 3ث).
- [ ] الوظائف العالقة تُستعاد عبر انتهاء القفل.

## المراقبة والسجلات
- [ ] سجلات منظّمة (JSON) بـ `correlation_id` — بلا نصوص مستخدمين/ملفات/مفاتيح.
- [ ] `/api/health` موصول بمراقبة المنصّة (200/503).
- [ ] تنبيه على 503 أو ذاكرة > 85%.

## الأمان
- [ ] لا `service role` في المتصفح.
- [ ] الفحص الصحي لا يكشف أسرارًا ولا storage_path (deployment-check يؤكّد).
- [ ] Prompt Injection داخل الملفات مُعامَل كمصدر غير موثوق (rag-check يؤكّد).
- [ ] رؤوس الأمان مضبوطة (`next.config.mjs`).

## الاختبارات قبل الإطلاق
- [ ] `npm run typecheck && npm run lint && npm run build && npm test` كلها خضراء.
- [ ] `node scripts/rag-check.mjs` = 22/22.
- [ ] `node scripts/rag-stress-check.mjs` = 20/20.
- [ ] `node scripts/deployment-check.mjs` ناجح.

## المخاطر المتبقية (راجعها قبل مستخدمين حقيقيين)
- [ ] Rate limiting داخل الذاكرة (يُستبدل بـ Redis/Upstash للتوسّع الأفقي).
- [ ] request-driven: التجهيز الطويل يشغل عملية الطلب — راقب مهلات المنصّة.
- [ ] لا نسخ احتياطي آلي مُوثّق لقاعدة البيانات بعد (اعتمد نسخ Supabase).
- [ ] حذف حساب المصادقة (`auth.users`) يتطلب service role — غير مُفعّل.

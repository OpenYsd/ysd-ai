# محرّكُ الصور المحلّيّ — العقدُ بين الويب والرفيق

> هذا المستندُ يصف **العقدَ** وحده. ولا يحوي رمزًا ولا مسارَ جهازٍ ولا
> سرًّا؛ ومحرّكُ التشغيل نفسُه يعيش **خارج هذا المستودع** ولا يُشحن معه.

## لماذا محلّيّ

التوليدُ يقع على جهاز المستخدم. لا خدمةَ مدفوعة، ولا معالجٍ رسوميّ
سحابيّ، ولا مفتاحَ واجهة، ولا كلفةَ على YSD لكلِّ صورة.

★ ولا سقوطَ إلى بديلٍ سحابيّ في أيّ حال. فإن تعذّر المحرّكُ فالجوابُ
خطأٌ مُعلَن — لا صورةٌ من مزوّدٍ مدفوع، ولا نداءُ محادثةٍ يُنفَق ثمنُه.

## الرايةُ رايةُ بناء

```
NEXT_PUBLIC_YSD_LOCAL_IMAGE
```

| القيمة | الحال |
|---|---|
| غائبٌ تمامًا | **مطفأة** (وهو وضعُ الإنتاج) |
| `""` أو `0` أو `false` أو أيُّ شيءٍ غير `1` | **مطفأة** |
| `1` حرفيًّا | مشتعلة |

★ **وهي رايةُ وقتِ بناء، لا وقتِ تشغيل.**

`NEXT_PUBLIC_*` يستبدله المُجمِّعُ نصًّا في حزمة المتصفّح، ثم يطوي
المُصغِّرُ الشرطَ إلى ثابت. فتغييرُ المتغيّر في لوحةِ الاستضافة **لا
يكفي**: يجب أن يُعاد البناءُ والنشر بعده.

ولا تُستبدل بضبطٍ بعيدٍ يُقرأ في التشغيل هربًا من إعادة البناء: ذلك
يفتح وصلةَ الحلقة المحلّية في السياسة قبل أن يُعرف أتُستعمل أم لا.

### ⚠ ملفّاتُ البيئة تسبق لوحةَ الاستضافة

وقع هذا فعلًا أثناء المراجعة: بُنيت حزمةٌ يُقصد بها الإطفاء، والمتغيّرُ
محذوفٌ من بيئة العمليّة — فخرجت **مشتعلة**، لأنّ `.env.local` في شجرة المشروع
يحويها لأجل التطوير المحلّيّ، وNext يقرأ تلك الملفّات عند البناء.

★ فلا يكفي أن تغيب الرايةُ من لوحة الاستضافة: يجب أن تغيب من كلّ
  ملفّ بيئةٍ يصل شجرةَ النشر كذلك. و`.env.local` مستثنىً من التتبّع في
  هذا المستودع، وهو ما يحمي الإنتاج — لكنّ الحمايةَ عرَضيّةٌ لا مقصودة،
  فتُفحص صراحةً قبل كلّ نشر.

ويُثبَت ذلك آليًّا:

```
node scripts/verify-local-image-flag.mjs
```

يبني الحزمةَ مرّتين ويقرأ الثابتَ المشحون — ويُنحّي ملفّاتَ البيئة
عند اختبار حالة «غائب» ثمّ يعيدها.

### أثرُها على سياسة المحتوى

مطفأة ⇒ `connect-src` كما هو حرفًا بحرف.
مشتعلة ⇒ يُضاف **عنوانٌ واحد** لا غير:

```
http://127.0.0.1:47615
```

ولا `127.0.0.1:*` — يُصرّح لكلِّ خدمةٍ على الجهاز.
ولا `localhost:*` — اسمٌ قد يُحلّ إلى غير الحلقة المحلّية.
ولا شبكةً محلّية ولا `0.0.0.0` ولا `ws://`.

وسائرُ التوجيهات لا تتغيّر: لا إرخاءَ في `script-src`، ولا
`'unsafe-inline'`، ولا `'unsafe-eval'` في الإنتاج.

## نقاطُ العقد

المنفذُ **مثبَّت**: `127.0.0.1:47615`. وعند تزاحمٍ عليه يمتنع المحرّكُ
ويُعلن، ولا يقفز إلى منفذٍ آخر — لأنّ القفزَ يستلزم توسيعَ السياسة.

| الطريق | الطلب | الرمز | المعنى |
|---|---|---|---|
| `GET /health` | بلا رمز | `200` | المحرّكُ يعمل. ولا يكشف شيئًا عن الجهاز |
| `GET /capabilities` | رمزٌ + أصلٌ مسموح | `200` | العتادُ والملفُّ والضبطُ المتاح |
| | | `401` | رمزٌ غائبٌ أو خاطئ |
| | | `403` | أصلٌ غيرُ مسموح |
| `POST /generate` | رمزٌ + JSON | `200` | تمّ التوليد |
| | | `403` | `hardware_profile_unverified` |
| | | `503` | `insufficient_local_resources` |
| | | `429` | `busy` — توليدٌ جارٍ |
| | | `500` | فشلٌ مُعلَن (منه رمزا الترجمة) |
| `GET /image/{id}` | رمز | `200` | بايتاتُ PNG |
| | | `404` | معرّفٌ غيرُ معروف |
| `POST /cancel` | رمز | `200` | إلغاءُ التوليد الجاري |

### المصادقة

يولّد المحرّكُ رمزًا عشوائيًّا **عند كلِّ تشغيل**، ويطبعه مرّةً في طرفيّة
صاحب الجهاز. والرمزُ محلّيٌّ بحت: لا صلةَ له بحساب YSD، ولا يصلح خارج
الحلقة المحلّية، ولا يُخزَّن في قاعدةٍ ولا يُرسل إلى خادم.

★ وهو غيرُ تفويضِ الأجهزة في YSD. ذاك يربط جهازًا بحساب، وهذا يمنع
صفحةً أخرى في المتصفّح من مخاطبة المحرّك. ولا يُضعَّف أحدُهما لأجل الآخر.

### رموزُ الفشل

| الرمز | العلاج |
|---|---|
| `hardware_profile_unverified` | العتادُ لم يُعايَر لهذه الميزة |
| `insufficient_local_resources` | ذاكرةٌ حرّة غيرُ كافية الآن (تُفرَّق البطاقةُ عن ذاكرة النظام) |
| `local_translation_model_not_installed` | المترجمُ العربيّ غيرُ مثبَّت |
| `local_prompt_translation_failed` | مثبَّتٌ وأخفق — إصلاحٌ لا إعادةُ تنزيل |
| `resolution_not_calibrated` | دقّةٌ لم تُقَس على هذا الجهاز |
| `busy` / `cancelled` / `timeout` | حالاتُ تشغيلٍ عاديّة |

★ ولا يقترح أيٌّ منها بديلًا مدفوعًا ولا سحابيًّا.

## الخصوصيّة

الطلبُ يخرج من الصفحة إلى `127.0.0.1` ولا يمرّ بخادم YSD أصلًا. فالوصفُ
والبذرةُ وبايتاتُ الصورة تبقى في الجهاز **بحكم الطريق لا بحكم الوعد**.

ولا يخرج من المحرّك مسارٌ مطلق: الصورةُ تُسلَّم بمعرّفٍ مُبهَم، إذ يحوي
المسارُ على وندوز اسمَ صاحب الجهاز.

★ ونتيجةُ هذه المرحلة **عابرة**: تعيش في ذاكرة التبويب، وتزول بتحديث
الصفحة. ولا رفعَ إلى Supabase، ولا حفظَ مسارٍ محلّيّ في قاعدة. و«الحفظ
في YSD» معطَّلٌ عمدًا حتى يُتّخذ قرارُ التخزين.

## ما يجري في المتصفّح

1. يُكشف طلبُ الصورة كشفًا **حتميًّا** — بلا نموذجٍ ولا نداءٍ مدفوع.
2. لا يُنادى `/api/chat` لطلبِ صورة: لا يُدفع ثمنُ جوابٍ نصّيّ لا يريده أحد.
3. تُخاطب الصفحةُ المحرّكَ مباشرةً؛ وتُترجم الأوصافُ العربيّة **في
   المحرّك** على المعالج المركزيّ.
4. تُعرض الصورةُ من عنوان كائنٍ في الذاكرة، ويُبطَل عند الحذف أو
   الاستبدال أو تفكيك المكوّن.
